# General script quality

The successful supplied storyboard had coordinated scenes spanning multiple
transcript sentences. Ordinary drafts previously used different authoring
paths by quality mode, clipped source pictures at sentence ends, and allowed
later finishing passes to overwrite complete performances.

All creation modes now use the same complete-passage story author. Photos have
their own planning slots, separate from actor actions. Exact move metadata and
grounded attacker/target roles are available before authoring. Sparse passages
receive a bounded repair attempt before asset downloads, while preserving a
usable original proposal if repair fails. Higher modes retain their additional
layout and frame review. Supplied explicit storyboards retain their execution
path. No previous episode's cast, plot or intro becomes a default.

Source picture performances use recording-wide intervals, split into render
layers without restarting their animation or entrance sound at a sentence cut.
Resolved named subjects, published mechanic images, items and nature assets
receive a delivered-visibility check. Missing or prematurely clipped source
reveals are recovered from the actual source files. Manual deletion, image
restrictions and protected footage remain authoritative. Missing sources are
reported instead of replaced by invented information graphics.

Complete attack and character performances are protected from generic animator,
shot-smoothing and attention passes. Charging a move to raise one's own stats
does not automatically attack the previously mentioned teammate. Move evidence
remains eligible in that situation, without an unrelated learner gallery.

Windows library commits retry brief scanner/file-lock failures using the same
atomic rename. Persistent storage failures still surface; the last good file
is never truncated as a workaround.

Regression checks cover passage completeness, cross-sentence visibility,
single entrance sounds, static-image requests, editable-object deletion,
fresh-edit state, source failures, protected performances and teammate context.
The multi-script diagnostic covers a general move explanation, a weather/support
partnership and a specific resisted matchup, using real original/published
assets and exported frames. Synthetic test narration is explicitly muted;
diagnostics do not save projects or modify user settings. Live Google search
and viewer retention are separate from these checks. No foundation-model
fine-tuning or guarantee of identical creative quality is claimed.
