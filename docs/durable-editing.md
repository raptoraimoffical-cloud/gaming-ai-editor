Editing tasks now have one shared cancellation owner across planning, image verification and rendering stages. Navigation and inspector changes do not abort them. The editor stays mounted when switching application tabs, and a global Stop editing control is available while work runs. Closing the application also cancels the current task. Trained-model requests use the task signal without automatic three/four-minute timeouts. Actual failures remain reported, and a stopped task cannot publish a partial result.

Completed project results are sent through production IPC to a root editor listener independently of the requesting panel. The preview reloads its composition and narration binding at the existing playhead. AI Changes checks the rendered composition/audio/caption signature: a response that changes only instructions or reports cannot claim it updated the video. No completion path writes project files automatically; explicit Save is the only project writer.

Every new generation/full remake allocates a fresh presentation family and storyboard approach, discards the previous authored timeline, and omits previous-plan input from model prompts. An in-memory counter selects presentation families without retaining projects, scripts or audio IDs. Each pass compiles its own placements, entrances and quiet game-pattern motion. Explicit placement choices, manual objects, narration, caption appearance and readable gameplay/chart evidence are protected. Version metadata is omitted from render payloads; the actual layers carry the variation.

Automatically detected or manually selected Pokemon Shorts receive a general gold-reference editing brief. Reference prompts share editing grammar and quality goals, without embedding example plots. Mystery silhouettes require an actual unnamed-Pokemon cue and start at its spoken time; a generic Pokemon game, tournament or news mention is insufficient. Even a genuine mystery hook has different staging families. Specific scenarios are regression cases, not global instructions.

Verification: `tests/durable-editing.test.mjs` checks cancellation ownership, request signals, version differences, context-only mystery hooks, reference scope and rejection of metadata-only changes. `scripts/check-durable-ai-changes.cjs` exercises the production main-process handlers, real backend and preload in Electron: a delayed edit survives Manual Edit/Game Music navigation and updates the preview; Stop cancels another edit without committing. `scripts/verify-fresh-version-renders.mjs` independently remakes the same actual saved narration twice and checks different compositions and PNG render hashes, preserved captions/timing and byte-identical original project files. Test versions remain in memory; only diagnostic images and reports are written.
