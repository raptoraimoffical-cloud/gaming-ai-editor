# Executing a supplied scene blueprint

The full Eric Rios recording exposed failures that the shorter picture tests did not cover. The editor interpreted a detailed scene-by-scene guide as general style prose, then allowed later generic passes to replace its requested shots. The word “professional” could select a restrained documentary layout, “restrained accent colors” could disable cinematic motion, and local scene colors and joke-caption sizes could become global preferences. A drifting logo could remain the only lead while the actual supporting picture stayed in a corner.

`scene-blueprint.mjs` now binds explicitly supplied `## SCENE` passages to the recording’s actual words. `blueprint-scenes.mjs` executes those passages with original source imagery, supplied team data, tracked held items, eased character interactions, word-timed mechanic pictures, and coordinated sound beats. An explicit user-authored blueprint does not need a model to invent a competing plan. Unsupported or missing sources are reported rather than replaced with a logo. Whole-video blueprint changes also use the newly submitted instructions, rather than a previous project's text.

This is a general parser and executor for current structured Pokémon instructions. Eric Rios, the tournament record, team members, spreads, jokes, and scene order live in the diagnostic fixture and the user's current instructions; they were not added to the default editing instructions. Unstructured requests continue through the existing model-backed planner, independent picture slots, and source resolver.

Global preferences stop before the scene-specific section. Authored interactions keep their keyframes. The final layout promotes an isolated automatic picture into the main visual area without changing deliberate manual placement. Make It Rain is a move cue, not a weather request. The explicit 60 FPS setting now propagates through preview timing, narration playback, frame review, and export.

Quiet scenery uses one cached crop/blur of the original arena image with overscan for camera movement. Reapplying an edit reuses that derivative without progressively cropping or blurring it. This caches source material; it does not cache or reload authored timelines. No editing project is automatically saved by the diagnostic.

The first complete export also exposed a late audio-mixing failure: the renderer tried to write to an already missing temporary directory after nearly all frames were captured. Exports now mix the same preview audio graph into temporary lossless PCM first, render graphics with audio disabled, and combine and normalize the streams afterward. Audio-source failures therefore surface before expensive video capture. The final audio receives one AAC encode rather than being encoded before and after normalization. `export-streams.mjs` tests the phase ordering, failure propagation, silence, and preservation of graphics settings. The standalone 66-cue audio diagnostic exercises a real full-duration 60 FPS mix.
